# Constant tables

This manifest lists every constant table in `src/tables.rs`. The file is generated by `tools/extract_tables.py` from the ITU-T reference software, which is the source of all values. The script copies the numbers unchanged and does nothing else with that software.

## Conventions

- Dimensions are listed outermost first. A table of 256 x 3 has 256 rows of 3 values. Indices start at 0 unless a description says otherwise.
- Floating-point tables (`f64`) come from the floating-point reference of Annex B. Values carry the precision printed there, typically six significant digits. Fixed-point tables with a floating-point counterpart are not duplicated.
- All tables are `pub static` items.
- Integer tables use the narrowest Rust integer type that holds every value of that table.
- Subframes are numbered 0 to 3. Coder rates are numbered 0 for the high rate (6.3 kbit/s) and 1 for the low rate (5.3 kbit/s).
- LSP frequencies in the floating-point tables are in units of pi/256 radian, so the range 0 to 256 spans 0 to 4 kHz and one unit is 15.625 Hz.
- The Recommendation text says that the values of the main body tables are given in the reference software, so most tables have no printed counterpart to compare with. The tables that are printed (Tables C.1a to C.1c, C.3a to C.3c, C.4, C.5a and C.5b) were compared with the extracted values, and the result is stated in their rows.
- Where a description says a relation was checked, the check was made on the extracted values.

## Items deliberately not extracted

- Fixed-point tables that have a floating-point counterpart in the same role (all main body tables, the VAD threshold scale and the SID gain quantizer tables).
- Tables that only collect other tables: the grouping of the three LSP codebooks and the grouping of the two pitch gain codebooks.
- Fixed-point helper tables without meaning in the Recommendation: the table of shift amounts used for normalisation.
- Sixteen-entry bit mask tables, whose entries are the powers of two 1, 2, 4 up to 32768 (the last stored as -32768 in 16-bit form).
- A 24-entry gain index map in the channel code that holds the identity 0 to 23.
- Initial state values: twenty values of 127 for the soft decision history and five values of 127 for the class means.
- Scalar constants beside the class tables: the reciprocals 2 to the power 20 divided by the class 0 size plus 4 are 24386 for the low rate, 19785 for the high rate and 26887 for SID frames.
- Table 1 of the Recommendation (ACELP pulse positions and signs) has no table in the reference software and is therefore not here.
